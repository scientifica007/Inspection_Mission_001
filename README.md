# Inspection_Mission_001

مشروع تطبيق/موقع لدعم مهام التفتيش الميداني، وجمع المعاينات والملاحظات والأدلة، ثم إنتاج المخرجات والتقارير.

## المصادر المرجعية الحالية

- `sources/01_field_control_and_equipment_aug_2026.md` — مراسلتان حول تفعيل الرقابة الميدانية على الورشات البيداغوجية وتأمين محيطها، وتحيين التجهيزات البيداغوجية على منصة «تسيير».
- `sources/02_provincial_entry_readiness_committee_2026_2027.md` — إنشاء لجنة ولائية لمتابعة مدى جاهزية المؤسسات التكوينية للدخول التكويني 2026–2027.

## قاعدة التعامل مع المصادر

مجلد `sources/` مرجع نصي للمشروع. لا تُعدَّل نصوصه عند اشتقاق متطلبات التطبيق. أي متطلبات، قوائم تحقق، مخططات بيانات، قواعد تحقق أو قوالب تقارير يجب أن تُنشأ في ملفات مستقلة مع الحفاظ على إمكانية تتبعها إلى المصدر الذي اشتُقت منه.

## المرحلة الحالية

المصادر النصية جاهزة. الخطوة التالية هي استخراج المتطلبات منها وتحويلها إلى كتالوج متطلبات، ومحاور تفتيش، وقائمة تحقق ومخطط بيانات قبل بدء التنفيذ البرمجي الجوهري.
